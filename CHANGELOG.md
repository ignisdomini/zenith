# Changelog

## 1.2.0 — 2026-09-14
- English interface (default) and Russian interface; language is chosen in the installer and in the settings.
- Bilingual installer with language selector and license in both languages.
- Star catalog builder rewritten in Node.js (`npm run catalog` downloads HYG v4.1 and Tycho-2 and builds the catalog).
- Latin constellation genitives for Bayer/Flamsteed designations in English («α Lyrae»).
- CSV export uses comma separators in English and semicolons in Russian.
- GitHub Actions build and release workflow.

## 1.1.0 — 2026-09-14
- Windows installer (NSIS) and portable build; developer information; About section.

## 1.0.0 — 2026-09-14
- Zenith map of 2.55 million stars and Solar System bodies on satellite and topographic base maps.
- Zenith passages through a ground area with tracks, entry and exit times.
- Anomalous zenith intersection points: concentrations, coinciding star tracks, crossings with bodies.
- CSV, KML and KMZ export.
